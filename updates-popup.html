WHAT'S NEW

Gamelist updates

Here are the latest changes to Gamelist:

  • Clearer PriceCharting lookup status

    Gamelist now identifies when PriceCharting blocks an automated lookup with a browser verification challenge, instead of reporting the game as missing.

  • A new Platform account connection system arrives!

    You can now connect IGDB, PlayStation, Xbox, Steam, and N**** directly from Settings. No more secrets needed! Follow the instructions shown for each platform.

    They are still as secure, and you probably might need to set them up again using the new system. Feel free to setup and delete the Secrets inside Cloudflare. Or just set it up and leave them there, it's fine. Also this will be very useful for when the PlayStation token expires and innevitably ask you for a new one.

  • Playtime fills in automatically!

    When you mark a game Completed or Finished, Gamelist now can get its playtime from your linked Steam, PlayStation, Xbox or Nintendo accounts. You can change the number yourself or use the reload button to fetch it again.

  • The big N is here. Connect your Nintendo account from Settings!

    It's finally here. Right now it doesn't do much as the API is limited and there is not achievements anyway, buy it will let you autofill your game time. Choose Log in with Nintendo, select your account, then copy the link address from Select this person and paste it into Gamelist.

  • New shelf stats

    New shelf statistics have been added to mirror the Gamelist ones. View at a glance when you got the games in your collection or your platform breakdown.

  • PriceCharting data no longer available

    Due to new strong protections set by PriceCharting the bot is no longer able to fetch the data for game prices from PriceCharting unless you pay for the Premium API, so right now that data will not be able to be updated by default.
