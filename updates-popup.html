WHAT'S NEW

Gamelist updates

Here are the latest changes to Gamelist:

  • New and improved shared Add Game system

    Both the Gamelist and Shelf add new game dialog have been streamlined and unified so now it doesn't matter on which page you are, you can easily add games to any in just a couple of click.

  • You can now more easily share your Gamelist and Shelf games

    If Shelf sync is enabled, you now will get prompted with a new window when Adding a game to backlog from Upcoming or Available, as well as if you add a new game directly to Backlog. It will have you add your collection status if physical or digital so you can more easily get that information added to Shelf. And from Shelf is the opposite, when adding to Backlog now it gets sent right away.
